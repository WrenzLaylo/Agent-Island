# Agent Island v0.2.1 — Quiet Idle and Return Home

This release focuses on making the island feel less like a floating AI widget and more like a native, passive system surface.

## Return to the original position

The original position is the top centre of the display currently containing Agent Island. It can now be restored in three ways:

- Choose **Return to top centre** from the system tray.
- Open Settings and choose **Return home**.
- Press **Ctrl/⌘ + Alt + Home** from anywhere.
- As a physical gesture, drag the island near the top centre of a display and release it. The window magnetically settles into the exact home position.

Returning home clears left/right docking, saves the top-centre position for that display, and collapses the interface back to the pill after the movement completes.

## Quiet idle mode

When no agent is running, thinking, waiting, completed, or in an error state, the collapsed island becomes a smaller pitch-black pill with no visible icon or copy. The docked idle state becomes a plain black circle.

Activity automatically restores the informative pill. Completed sessions remain visible briefly, then return to the black idle state. If another agent is active in the background, that agent is surfaced rather than hiding the activity.

The behaviour is enabled by default and can be changed using **Quiet idle pill** in Settings or the system tray.

## Typography

Inter was removed from the interface stack. The application now uses native platform typography:

- Segoe UI Variable Text / Segoe UI Variable on current Windows versions
- SF Pro Text through the macOS system font stack
- Segoe UI or system-ui fallbacks elsewhere

Weights and tracking were reduced to avoid the over-designed, generated-dashboard appearance. Monospace text remains reserved for commands and diagnostics.

## Interaction details

- Idle hover no longer opens the interface automatically; click remains available.
- Working, waiting, completed, and error states continue to reveal information automatically.
- Successful session completion remains visible for approximately 2.2 seconds before returning to idle.
- The native rounded window mask continues to update throughout movement and resizing.
