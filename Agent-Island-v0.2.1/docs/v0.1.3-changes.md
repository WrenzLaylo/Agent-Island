# v0.1.3 changes

- Approval confirmations now return to the compact pill automatically after a brief acknowledgement, even while the pointer remains over the expanded island.
- Hermes bridge approvals now preserve and display the choices exposed by Hermes: Allow once, Allow for this session, Add to permanent allowlist, and Deny.
- Decisions are validated against the live pending request before they are written back to Hermes.
- Added native rounded window shaping on Windows and Linux so the Electron window cannot paint a rectangular background outside the island.
- Removed full-window macOS vibrancy/backdrop blur and kept the self-contained glass material to avoid a rectangular translucent panel.
- Added an inline transparent document background to prevent startup flashes.
- Removed the unused Zustand dependency.
