# Agent Island v0.2.0 — Core Experience

## Interaction model

- Quiet compact pill for idle and working states.
- Click-only restoration from the docked circle; hovering a docked orb does not expand it.
- Approval requests can auto-expand or remain in the attention pill, depending on settings.
- Resolved, denied, expired and cancelled requests collapse automatically after a short confirmation.
- Multiple approvals remain in a FIFO queue; the island moves directly to the next request without collapsing.

## Approval experience

- Displays the command, working folder, risk level and why Hermes flagged it.
- Supports the permission choices Hermes actually exposes: Allow once, Allow for this session, Add to permanent allowlist and Deny.
- Permanent allowlisting requires a second confirmation explaining the future scope.
- Stale, expired, superseded and closed requests are removed from the queue with a clear transient message.

## Motion and windowing

- The BrowserWindow and its native rounded mask interpolate together during expansion and collapse.
- The same glass surface remains mounted while inner content crossfades.
- Docked expansion stays anchored to the selected screen edge.
- Position and docking are saved independently per display.
- Reduced-motion mode shortens morphs and disables decorative loops.

## Multi-agent experience

- Claude, Codex and Hermes use distinct restrained marks.
- The switcher only shows detected, active or attention-needing agents.
- Approvals automatically focus the requesting agent.
- The selected agent can be remembered between launches.

## Settings and tray

- Added system tray controls for visibility, always-on-top, startup launch, auto-expansion, sounds, motion, docking and diagnostics.
- Added an in-island settings panel with glass intensity and auto-collapse timing.
- Added first-run onboarding for dragging, docking and approval behaviour.

## Visual refinement

- Removed the hardcoded Hermes presentation.
- Reduced glow, gradients and nested glass effects.
- Kept the window, document root and stage fully transparent.
- Disabled Chromium backdrop filtering on Windows and used layered glass instead, avoiding the rectangular transparent-window artefact on affected GPU/scaling combinations.
- Shadows and highlights belong only to the visible island surface.
