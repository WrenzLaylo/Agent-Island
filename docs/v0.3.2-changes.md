# v0.3.2 — silhouette, motion, and shell rebuild

## Rendering: the island is no longer clipped by a native region

`BrowserWindow.setShape()` used to clip the HWND to a scanline approximation of
a rounded rectangle. A native window region has **no anti-aliasing**, so every
corner it cut came out as a hard staircase — visible as "jagged" pill edges —
and it fought the correctly anti-aliased CSS `border-radius` underneath.

The shape only ever existed to hide a `backdrop-filter` artefact, and the
surface has been opaque black since v0.2.2, so:

- `roundedWindowShape()` / `applyWindowShape()` and `WINDOW_SHAPE_INSET` are gone.
- The 5px `.stage` padding and `.island-frame` inset that reserved room for the
  mask are gone: **the window is now exactly the visible island**.
- Sizes in `sizeForPresentation` are literal on-screen pixels.

Trade-off: the transparent wedges outside the rounded corners now belong to the
window, so a click landing in one hits the island rather than passing through.
The affected area is a few pixels per corner.

## Motion: one animation instead of two fighting each other

Geometry was animated twice — `setTimeout(16)` + `easeInOutCubic` on the OS
window in main, and a framer-motion `layout` spring on `.island-surface` in the
renderer — on different curves, while `AnimatePresence mode="wait"` ran a
~470ms exit-then-enter content swap against a ~290ms window morph.

- The window is now driven by a **critically damped spring** integrated at a
  fixed 1/240s sub-step (no overshoot, frame-rate independent).
- `layout` and the surface spring are removed. Content only cross-fades, and
  views overlap (`.island-content` is absolutely positioned) instead of queueing.
- `applyWindowShape` is no longer rebuilt per frame.

Measured: 116×32 → 400×172 settles in ~415ms, monotonic, no overshoot.

## Click-outside-to-collapse is now reliable

Collapsing rides on the window's `blur` event, and **a window that never held
focus never blurs**. Anything raised with `showInactive()` — an approval
arriving while you work elsewhere, or one restored from the bridge at launch —
expanded and then ignored every click on the rest of the screen.

`showIsland({ focus })` now focuses when the island is demanding a decision
(approvals with auto-expand on, terminal handoff, tray "Open", settings, and
approvals restored at startup) and stays inactive for ambient changes.

## Docked state

- **Fixed:** the global `.status-waiting { background }` rule (meant for
  `StatusDot`) leaked onto `.dock-status-ring`, which shares the `status-*`
  suffix. A docked island with a pending approval rendered as a **solid amber
  disc**. Status colours are now scoped to `.status-dot`.
- The approval badge sat on the bounding-box corner and was sliced in half by
  the circular clip. It now sits inside the disc (tangent at 6px inset) and
  caps at `9+` so it stays round.
- The agent mark no longer fills the whole orb; the ring carries status.
- Dead `anchored-left` / `anchored-right` classes removed.

## Design system

`globals.css` was 1548 lines whose last ~230 overrode the first ~1300 with
`!important` — the entire glass/gradient system was dead but still shipped. It
is now a single token-driven sheet: **5 type steps (nothing below 11px, down
from nine sizes including 7px and 8px), 4 radii (down from fourteen), a 4px
spacing scale, one duration and one easing.**

Content duplication removed:

- Overview showed the agent name and activity label in the header and repeated
  both in a large status card ("Claude" / "Claude is ready" / "Installed and
  ready"). Status headlines are now name-free and the supporting line states a
  different fact.
- The approval header said "Approval required · Hermes is paused" above a card
  that said "Hermes needs permission · Hermes is paused until you decide".
- The compact pill said "1 pending" next to a "1" chip.

## Reliability

- **Single-instance lock.** Two copies shared one userData dir, one settings
  file, one approval-bridge folder and one set of global shortcuts, and either
  could answer the same approval. A second launch now surfaces the first.
- **Layout persistence is coalesced.** `saveDisplayLayout` ran a synchronous
  `writeFileSync` + `renameSync` from the window's `moved` event — ~60 blocking
  disk writes per second while dragging. Now debounced (400ms), skipped when
  unchanged, and flushed on quit.
- **Prompt scanning is bounded.** `scanInteractions` re-stripped ANSI over the
  entire replay buffer (up to 80k chars) on *every* PTY chunk. It now normalises
  a 24k tail once and shares it with all detectors.
- **Bridge requests survive a BOM.** `JSON.parse` rejects a leading U+FEFF, and
  the failure was swallowed silently, so a pending file written by PowerShell,
  .NET or a Windows editor made the agent wait forever for a decision that would
  never appear. Parse failures are now stripped of the BOM and logged.
- `display-added` / `display-removed` re-clamp the island, not just
  `display-metrics-changed`.
- A rejected `island:resize` no longer leaves every control inert behind
  `is-morphing`.

## Accessibility

- `aria-live="polite"` moved off the whole island (which re-announced every
  control on every render) onto a visually hidden status line.
- Minimum type size raised from 7px to 11px.

## Removed

`spring.ts`, `DemoControls.tsx`, `MultiAgentTerminals.tsx` and
`TerminalPanel.tsx` — 590 lines, none of them imported anywhere.
