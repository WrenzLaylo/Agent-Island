# v0.3.1 changes

- Added conservative detection for plan mode, numbered selections, typed questions, and authentication prompts across managed Claude, Codex, and Hermes sessions.
- Added a dedicated **Continue in Terminal** handoff panel instead of guessing unsupported answers.
- Added one managed terminal window per agent using the existing PTY session and scrollback.
- Moves an existing managed terminal from another monitor to the display containing Agent Island, then restores and focuses it.
- Preserves a maximised terminal when it is already on the correct display.
- Added a manual terminal button to the expanded agent overview.
- Suppresses repeated island alerts after a prompt has already been handed to the terminal.
- Keeps known Hermes and Codex permission prompts on their dedicated approval paths.
- Added parser tests for Claude plan mode, Codex plan choices, known approval exclusion, and duplicate handoff suppression.
