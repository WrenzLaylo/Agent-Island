# v0.1.2 changes

- Replaced the Hermes-only renderer initialisation with discovery-driven Claude, Codex, and Hermes availability.
- Added a compact animated agent switcher that only shows detected agents.
- Added agent-specific marks throughout the pill, docked orb, expanded header, and approval state.
- Incoming approvals automatically select the requesting agent.
- Kept one glass surface mounted across UI states so the shell itself morphs instead of being replaced.
- Added a 245 ms interpolated Electron bounds animation for smoother pill-to-expanded and expanded-to-pill transitions on Windows.
- Added PTY session/exit event forwarding so existing managed sessions can report their status to the HUD.
- Removed the unused Zustand dependency.
- Kept the Hermes approval bridge scope explicit; Claude/Codex external-terminal attachment and approval adapters are not represented as complete.
